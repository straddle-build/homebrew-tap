# Straddle Homebrew Tap

Homebrew tap for Straddle CLI tools.

## Install

```sh
brew install straddle-build/tap/straddle
```

Casks in this tap are generated by the GoReleaser release workflow of
[straddle-build/straddle-cli](https://github.com/straddle-build/straddle-cli).
`main` accepts changes only through pull requests, so each release pushes
`Casks/straddle.rb` to a `straddle-<version>` branch and opens a pull request
that a maintainer reviews and merges.
